Implemented safeguards

  • Default build and build:release require explicit private-beta/production target, reviewed HTTPS Supabase endpoint and public anon/publishable key. Missing configuration, privileged keys, localhost release endpoints and demo flags fail closed. Legacy .env configuration is not silently reused.
  • Release bundle rejects known fixture/legacy modules; publicDir:false excludes stock public assets. Session keys are isolated by environment and endpoint. Missing media service disables uploads with an explanatory prompt.
  • New authentication alone creates no family, invitation, post, business or conversation. Family identity/membership still requires the approved invitation or provisioning process.
  • Empty home, messages, businesses and missing identity views use onboarding prompts. Profile and family tree fallbacks use initials. Generic template titles and PDF metadata no longer default to Bennett/Reed.
  • Local fictional template studio is explicitly opt-in and visibly separate. It does not import sample people into account records. Release contains neither its link nor module; direct demonstration URLs cannot load it.

Limitations and remaining gates

  • Hosted content was not inspected. This cannot certify that hosted tables or buckets contain no examples. Preserve both existing hosted Auth accounts; review hosted provenance before any approved migration.
  • Use reviewed schema-only migrations; never restore development Auth/data dumps or storage buckets into beta. Software cannot reliably identify manually entered fictional records or arbitrary uploaded stock images.
  • Explicit configuration prevents accidental development fallback, but cannot certify a deliberately selected remote database. Candidate data/bucket review remains a release gate.
  • Existing engines and templates remain available locally. The fictional studio is excluded from release; a real-family print workflow is separate work.
  • Hosted email/media configuration, real-device verification, operations and deployment approval remain outstanding. No release was deployed.
